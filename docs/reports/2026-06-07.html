经典工作详细讲解

本讲是“GRB 从零到前沿课程”的第 \(1/6\) 讲。前置桥梁课已经介绍过高能天体物理中共同的观测语言，例如光变曲线、能谱、通量、fluence、红移和 luminosity distance；本讲第一次进入 GRB 专题，目标不是马上解释 prompt 辐射机制，而是先建立一个更基础的判断：为什么 GRB 不能是一个普通静止小源，为什么任何后续模型都必须包含超相对论运动。本讲会覆盖发现、距离尺度、短时标、高光度、非热谱、紧致性问题和相对论火球图像；内激波、光球辐射、磁重联和 afterglow 动力学将留到后续几讲。

GRB 的科学问题最初来自一个非常不寻常的发现路径。Klebesadel 等人在 \(1973\) 年报告的伽马射线暴不是由传统光学望远镜发现的，而是由监测核试验的 Vela 卫星记录到的短时标伽马射线闪光。早期研究者首先要回答的并不是“辐射机制是什么”，而是“这些信号是否来自地球附近、太阳系、银河系，还是宇宙学距离”。这个距离问题至关重要，因为同样的观测 fluence \(S\) 若放在不同距离，对应的能量预算会相差许多数量级。

随着 BATSE 等全天监测样本积累，GRB 的几个观测事实逐渐变得清楚。第一，持续时间覆盖很宽，从 \(\sim 10^{-2}\,{\rm s}\) 到 \(\sim 10^{3}\,{\rm s}\)，并且许多光变曲线含有亚秒甚至更短的尖锐结构。第二，prompt 能谱通常在 \(\sim 10^{2}\,{\rm keV}\) 到 \(\sim {\rm MeV}\) 附近达到 \(\nu F_\nu\) 峰值，并带有明显非热幂律尾。第三，天空分布近似各向同性，不沿银河盘集中。第四，在余辉定位和红移测量确认宇宙学距离后，典型各向同性等效能量 \(E_{\rm iso}\) 可达 \(10^{51}\) 到 \(10^{54}\,{\rm erg}\)，各向同性等效光度 \(L_{\rm iso}\) 可达 \(10^{50}\) 到 \(10^{53}\,{\rm erg\,s^{-1}}\)。这些事实合在一起形成一个强约束：一个变化很快、能量很高、谱又非热的源，如何让高能光子逃出来？

朴素的非相对论估计会立刻陷入矛盾。如果光变中最窄的显著结构宽度为 \(\delta t\)，静止源的因果尺度通常写成 \(R\lesssim c\delta t/(1+z)\)。当 \(\delta t\sim 10^{-2}\,{\rm s}\) 时，源区尺度只有致密天体量级；若同时采用宇宙学距离推得的 \(L_{\rm iso}\)，则源内光子数密度极高。能量足够高的两个光子可以通过 \(\gamma\gamma\rightarrow e^+e^-\) 产生电子正电子对，其阈值由 \(E_1E_2(1-\cos\theta)\gtrsim 2(m_ec^2)^2\) 控制。数量级估计会得到 \(\tau_{\gamma\gamma}\gg 1\)，也就是说源应当对自身伽马光子高度不透明。

这个矛盾就是 Goodman \(1986\) 等经典工作所强调的 compactness problem。若 \(\tau_{\gamma\gamma}\gg 1\)，光子会被反复吸收、散射和重处理，辐射场倾向于热化，最终输出应更接近准黑体或被严重削弱，而不是观测到的快速变化、宽频非热 MeV 光谱。因此问题不是“能不能产生很多伽马光子”，而是“在这么小的视在时空尺度和这么高的 luminosity 下，伽马光子为什么没有被自己的同伴吃掉”。这一步是后续所有 prompt 模型必须先通过的物理门槛。

相对论运动解决 compactness problem 的关键在于它同时改变三个环节。第一，观测到的短时标不再对应简单的 \(R/c\)，因为以 bulk Lorentz factor \(\Gamma\gg 1\) 朝向观测者运动的薄壳具有相对论到达时延，允许辐射半径达到 \(R\sim 2\Gamma^2c\delta t/(1+z)\)。第二，源的共动系中光子能量降低，数量级上 \(E'\sim E(1+z)/\Gamma\)，超过成对产生阈值的目标光子比例下降。第三，共动系光子能量密度也降低，典型估计为 \(u'_\gamma\sim L_{\rm iso}/(4\pi R^2c\Gamma^2)\)。因此 \(\tau_{\gamma\gamma}\) 会随 \(\Gamma\) 的高次幂快速下降，通常给出 \(\Gamma_{\rm min}\sim 10^2\) 或更高的下限。

Paczynski、Rees 和 Mészáros 等工作的历史意义在于把宇宙学距离、高 luminosity、相对论膨胀和火球动力学放进同一幅图像。所谓相对论火球并不等同于某一个具体 prompt 辐射机制；它首先表示中心引擎在小尺度内释放巨大能量，形成辐射、电子正电子对和少量重子组成的高压 outflow，随后通过膨胀把内部能转化为 bulk kinetic energy。若注入能量为 \(E_0\)，夹带重子质量为 \(M_b\)，则理想极限 Lorentz 因子由 \(\eta=E_0/(M_bc^2)\) 决定。紧致性要求 \(\Gamma\gtrsim 10^2\)，因此也要求重子污染不能过大。

本讲的局限也必须在一开始说明清楚。我们会使用各向同性等效量 \(E_{\rm iso}\) 和 \(L_{\rm iso}\)，但真实 GRB 往往是准直喷流，真实释放能量可低于 \(E_{\rm iso}\)。我们会用单一区域、单一 \(\delta t\)、简单谱指数和近似角分布推导 \(\Gamma_{\rm min}\)，但真实 prompt 辐射可能具有多脉冲、多区辐射、时间依赖谱演化、光球成分、磁化 outflow 和复杂探测选择效应。紧致性论证不能告诉我们 prompt 光子究竟来自 optically thin synchrotron、photospheric Comptonization 还是 magnetic reconnection；它只告诉我们：若没有相对论 outflow，后续解释都无法成立。

这个结论对整个 GRB 研究具有持续影响。Fermi/LAT 探测到的 GeV 光子使 compactness 约束更加严格，因为高能光子更容易与 MeV 目标光子成对产生。后续讨论 prompt 光谱时，\(E_{\rm pk}\)、高能谱指数和最高能光子 \(E_{\rm max}\) 会进入 \(\tau_{\gamma\gamma}\) 估算；讨论 afterglow 时，早期峰值时间和外激波动力学也能反推 \(\Gamma\)；讨论多信使事件时，viewing angle 和结构化喷流会改变我们对 \(L_{\rm iso}\) 与真实能量的理解。但无论模型怎样发展，\(\tau_{\gamma\gamma}<1\)、\(R\sim 2\Gamma^2c\delta t/(1+z)\) 和 \(\Gamma\gg 1\) 仍是现代 GRB 课程的第一块地基。

背景知识

GRB 研究的历史起点带有强烈的冷战时代背景。Vela 卫星原本用于监测违反核试验禁令的高能辐射信号，却记录到一些短暂、强烈、无法归因于地面或太阳活动的伽马射线闪光。Klebesadel 等人在 \(1973\) 年公布这些事件后，天文学界面对的是一种几乎没有先例的瞬变现象：它们发生得很快，主要能量在伽马射线波段，早期定位又很差。由于缺少精确方向和距离，研究者一开始无法判断这些事件是近邻天体、银河系源还是宇宙学爆发。

距离尺度之所以成为核心，是因为高能天体物理中能量预算对距离极其敏感。若观测 fluence 为 \(S\)，源位于 luminosity distance \(d_L\)，则各向同性等效能量数量级为 \(E_{\rm iso}\simeq 4\pi d_L^2S/(1+z)\)。如果 \(d_L\) 只是太阳系或银河系尺度，能量可能尚可由局部天体解释；如果 \(d_L\) 是宇宙学尺度，\(E_{\rm iso}\) 会变成超新星甚至更高量级的能量释放。早期关于 GRB 起源的争论，本质上就是在不同距离尺度之间权衡观测事实和物理可行性。

全天分布是早期突破的关键线索。BATSE 的大样本显示 GRB 在天球上近似各向同性，没有明显沿银河盘集中。这一事实削弱了普通银河盘源模型，因为银河盘中的天体通常会在 Galactic latitude \(b=0^\circ\) 附近形成显著集中。同时，\(\log N-\log P\) 或 \(\log N-\log S\) 分布在暗端偏离均匀欧氏空间中 \(N(>P)\propto P^{-3/2}\) 的简单预期，提示样本受到宇宙学几何、源演化、luminosity function 或探测阈值影响。后来 BeppoSAX 余辉定位和红移测量最终确认许多长暴确实位于宇宙学距离。

短时标是本讲最重要的观测量之一，但它常被初学者误解。GRB 的 \(T_{90}\) 描述的是累计探测到 \(90\%\) fluence 所需的总时间，它适合做分类和总体持续时间描述；compactness problem 真正需要的是光变曲线中最窄且统计显著的结构宽度 \(\delta t\)。如果一个脉冲或子结构在 \(\delta t\sim 10^{-2}\,{\rm s}\) 内变化，非相对论因果性会给出 \(R\lesssim c\delta t/(1+z)\)，也就是 \(\sim 10^8\) 到 \(10^9\,{\rm cm}\) 的尺度。这种尺度接近致密天体，却要释放宇宙学 GRB 的巨大 luminosity。

非热谱提供了另一个独立约束。许多 prompt 谱可用 Band 函数近似，即在低能端和高能端分别表现为幂律，中间在 \(E_{\rm pk}\) 附近转折。这样的宽谱和高能尾说明光子没有在高光深环境中完全热化。若源是一个静止、紧致且高 luminosity 的伽马光子团，\(\gamma\gamma\) 吸收和电子正电子对产生会使 \(\tau_{\gamma\gamma}\) 远大于 \(1\)，辐射应当被热化或至少被强烈重处理。观测到的非热 MeV 谱因此与非相对论 compact source 图像直接冲突。

各向同性等效量也容易引发误区。\(E_{\rm iso}\) 和 \(L_{\rm iso}\) 并不一定等于真实总能量和真实总 luminosity，因为 GRB 通常是喷流，若喷流半开角为 \(\theta_j\)，真实能量可能小于各向同性等效能量。然而在 compactness 估算中，观测者位于喷流可见锥内，沿视线方向的辐射密度仍可用 \(L_{\rm iso}\) 作为直接可观测的输入量。也就是说，喷流准直能缓解总能量预算，却不能自动消除局部光子密度和透明性问题。

另一个常见误区是以为相对论运动只是为了解释 GeV 光子。事实上，即使没有 GeV 探测，只要 GRB 在宇宙学距离上具有 \(L_{\rm iso}\sim 10^{52}\,{\rm erg\,s^{-1}}\)、\(\delta t\sim 10^{-2}\,{\rm s}\) 和 MeV 级非热光子，静止源也会非常不透明。GeV 光子只是把问题放大，因为它们对 \(\gamma\gamma\) 吸收更敏感，能把 \(\Gamma_{\rm min}\) 推得更高。紧致性问题的核心并不是“有没有最高能光子”，而是“短时标、高 luminosity 和非热透明辐射能否同时成立”。

还需要区分“火球图像”和“prompt 辐射机制”。火球图像的基本命题是中心引擎释放的能量会驱动一个相对论 outflow，并通过大 \(\Gamma\) 解决透明性和时间尺度矛盾；它并不预设观测到的 prompt 光子一定由内激波、光球、同步辐射或磁重联产生。本讲故意停在这个边界上：我们只建立相对论 outflow 的必要性，不展开各种耗散和辐射机制的优劣。下一讲才会把 Band 谱、\(E_{\rm pk}\)、低能谱指数、高能谱指数和辐射机制候选系统连接起来。

基础理论 / 方法脉络

理解 GRB 的第一步，是把它看成一个由观测量反推物理条件的问题，而不是先选一个辐射机制。观测上我们得到的是 light curve、spectrum、fluence、peak flux、最高能光子和有时可得的 redshift；物理上我们想知道的是源区半径 \(R\)、bulk Lorentz factor \(\Gamma\)、光子密度、光深 \(\tau_{\gamma\gamma}\) 和能量预算。本讲的中心逻辑是：从短时标和高 luminosity 出发，先证明静止源不透明，再说明相对论 outflow 如何使源透明。

课程边界需要先讲清楚。前置桥梁课已经讲过通量、能谱和时间序列等共同语言；本讲只把这些观测语言用于 GRB 的基本判据。我们暂不讨论 prompt 光谱的具体物理来源，也不推导 afterglow 外激波的 Blandford-McKee 解。换句话说，本讲回答“为什么必须有 \(\Gamma\gg 1\)”，下一讲再回答“在 \(\Gamma\gg 1\) 的 outflow 中，prompt 光子可能怎样产生”。

最常用的观测入口包括 fluence \(S\)、峰值能量通量 \(F_{\rm pk}\)、总持续时间 \(T_{90}\)、最小显著变时标 \(\delta t\)、谱峰 \(E_{\rm pk}\)、最高能光子 \(E_{\rm max}\) 和红移 \(z\)。若已知 luminosity distance \(d_L(z)\)，可定义 \(E_{\rm iso}\simeq 4\pi d_L^2S/(1+z)\) 与 \(L_{\rm iso}\simeq 4\pi d_L^2F_{\rm pk}\)。这些量不是最终的真实能量和真实 luminosity，而是把观测数据转化为紧致性估算的标准坐标。

非相对论紧致源的困难来自光子数密度。若源的 luminosity 为 \(L\)，半径为 \(R\)，平均光子能量为 \(\langle E\rangle\)，则光子数密度数量级可写为 \(n_\gamma\sim L/(4\pi R^2c\langle E\rangle)\)。若再用静止源因果性估计 \(R\lesssim c\delta t/(1+z)\)，一个高 luminosity 且快速变化的 GRB 会具有极大的 \(n_\gamma\)。这一步并不需要复杂模型，只使用能量流穿过球面和光速传播的基本图像。

成对产生给出了透明性诊断。两个光子能量分别为 \(E_1\) 和 \(E_2\)，夹角为 \(\theta\)，当 \(E_1E_2(1-\cos\theta)\gtrsim 2(m_ec^2)^2\) 时可以发生 \(\gamma\gamma\rightarrow e^+e^-\)。在静止小源中，光子方向近似不强烈准直，\(1-\cos\theta\) 不小；同时 MeV 附近的光子数量很多，因此 \(\tau_{\gamma\gamma}\sim n_\gamma\sigma_{\gamma\gamma}R\) 很容易远大于 \(1\)。这与我们看到的非热透明 prompt 谱矛盾。

相对论运动首先改变时间尺度和半径的关系。对于以 \(\Gamma\gg 1\) 朝向观测者运动的薄壳，同一半径上不同角度区域发出的光子存在角向到达时延，观测变时标满足 \(\delta t_{\rm obs}\sim (1+z)R/(2\Gamma^2c)\)。因此同样的 \(\delta t_{\rm obs}\) 不再意味着 \(R\sim c\delta t_{\rm obs}\)，而允许 \(R\sim 2\Gamma^2c\delta t_{\rm obs}/(1+z)\)。半径增大后，光子密度随 \(R^{-2}\) 显著下降。

相对论运动还改变能量和角分布。在 outflow 的共动系中，观测到的光子能量数量级降低为 \(E'\sim E_{\rm obs}(1+z)/\Gamma\)，许多高能光子不再容易超过成对产生阈值。与此同时，相对论 beaming 使光子在观测者方向上集中，碰撞角在共动描述中也受到限制，从而降低有效 \(1-\cos\theta\)。再加上共动能量密度 \(u'_\gamma\sim L_{\rm iso}/(4\pi R^2c\Gamma^2)\) 的下降，\(\tau_{\gamma\gamma}\) 会随 \(\Gamma\) 快速减小。

火球图像把这种透明性要求与动力学连接起来。中心引擎在小半径注入能量 \(E_0\)，同时不可避免地夹带一定重子质量 \(M_b\)。若初始能量主要以辐射和对等离子体形式存在，膨胀过程中内部能可转化为 bulk kinetic energy，理想极限由 \(\eta=E_0/(M_bc^2)\) 控制，最终 coasting 阶段通常有 \(\Gamma\sim \eta\)。因此 \(\Gamma\gtrsim 10^2\) 不只是辐射转移条件，也是对重子污染的动力学约束：\(M_b\) 不能大到拖慢 outflow。

本讲的观测分析逻辑是反向闭合的。我们不从某个 prompt 模型开始，而是从 \(L_{\rm iso}\)、\(\delta t\)、\(E_{\rm max}\) 和谱形出发，要求最高能光子能够逃逸，即 \(\tau_{\gamma\gamma}(E_{\rm max},\Gamma)<1\)，从而得到 \(\Gamma_{\rm min}\)。读论文时要检查这些输入量是否来自同一时间窗、同一辐射成分和可信的探测器响应；尤其要区分 \(T_{90}\) 与 \(\delta t\)，也要检查最高能光子是否与 MeV prompt 发射共时。只有掌握这条基础链条，后面讨论 Band 函数、同步辐射、光球、磁化喷流和 afterglow 时，才不会把模型自由参数误当成物理解释。

公式与推导

第一步：先把观测量放到统一的能量尺度上。前置桥梁课已经定义过 fluence 和 luminosity distance；本讲把它们用于 GRB。若观测 fluence 为 \(S\)，红移为 \(z\)，luminosity distance 为 \(d_L\)，则各向同性等效能量为

\[E_{\rm iso}\simeq {4\pi d_L^2S\over 1+z}\, .\]

这里假设辐射在角向上先按各向同性等效处理，因子 \((1+z)^{-1}\) 把观测时间尺度换回源系能量释放尺度。若真实源是喷流，\(E_{\rm iso}\) 不是总能量，但它仍是从观测 fluence 进入紧致性估算的第一步。

第二步：再把峰值通量转换为瞬时 luminosity。若峰值能量通量为 \(F_{\rm pk}\)，则

\[L_{\rm iso}\simeq 4\pi d_L^2F_{\rm pk}\, .\]

这一步求出的 \(L_{\rm iso}\) 是后面估计光子密度的核心输入。读论文时要注意 \(F_{\rm pk}\) 的时间窗，因为 compactness 约束需要与最短显著变时标和最高能光子尽量来自同一段 prompt emission。

第三步：如果源不做相对论运动，短时标直接给出紧致半径。设光变曲线中最窄且统计显著的结构宽度为 \(\delta t_{\rm obs}\)，非相对论因果性给出

\[R_{\rm nr}\lesssim {c\delta t_{\rm obs}\over 1+z}\, .\]

这里的假设是辐射区整体近似静止或没有以 \(\Gamma\gg 1\) 朝向观测者运动。这个半径通常只有致密天体量级，下一步会看到它与高 luminosity 结合后导致极高光子密度。

第四步：用能量流守恒估计静止源中的光子数密度。若平均光子能量为 \(\langle E\rangle\)，则

\[n_{\gamma,\rm nr}\sim {L_{\rm iso}\over 4\pi R_{\rm nr}^2c\langle E\rangle}\, .\]

这一步只使用 luminosity 穿过半径为 \(R_{\rm nr}\) 的球面这一数量级图像。由于 \(n_{\gamma,\rm nr}\propto L_{\rm iso}\delta t_{\rm obs}^{-2}\)，高 luminosity 和短变时标会把光子数密度推到极高水平。

第五步：由光子数密度得到非相对论 \(\gamma\gamma\) 光深。成对产生截面的峰值约为 Thomson 截面的 \(0.1\) 倍，记作 \(\sigma_{\gamma\gamma}\sim 0.1\sigma_T\)，则

\[\tau_{\gamma\gamma,\rm nr}\sim n_{\gamma,\rm nr}\sigma_{\gamma\gamma}R_{\rm nr}\sim {L_{\rm iso}\sigma_{\gamma\gamma}\over 4\pi R_{\rm nr}c\langle E\rangle}\, .\]

把 \(R_{\rm nr}\lesssim c\delta t_{\rm obs}/(1+z)\) 代入后，典型宇宙学 GRB 会得到 \(\tau_{\gamma\gamma,\rm nr}\gg 1\)。这意味着静止小源应当对自身伽马光子不透明，与观测到的非热 prompt 光谱矛盾。

第六步：透明性矛盾的微观来源是成对产生阈值。两个光子能量为 \(E_1\) 和 \(E_2\)，夹角为 \( heta\)，发生 \(\gamma\gamma\rightarrow e^+e^-\) 的阈值近似为

\[E_1E_2(1-\cos\theta)\geq 2(m_ec^2)^2\, .\]

这个关系说明最高能光子是否能逃逸，不只取决于自身能量，也取决于目标光子能量和碰撞角。静止紧致源中光子方向不强烈准直，\((1-\cos\theta)\) 通常不小，因此 MeV 光子场会高效吸收更高能光子。

第七步：引入相对论壳层后，观测变时标不再等于 \(R/c\)。若辐射区以 bulk Lorentz factor \(\Gamma\gg 1\) 朝向观测者运动，同一半径上不同角度的光子有角向到达时延，满足

\[\delta t_{\rm obs}\sim (1+z){R\over 2\Gamma^2c}\, ,\qquad R\sim {2\Gamma^2c\delta t_{\rm obs}\over 1+z}\, .\]

这一步解出的 \(R\) 比非相对论估计大 \(\sim 2\Gamma^2\) 倍。半径增大是降低光子密度的第一重相对论效应。

第八步：相对论运动还降低共动系中的光子能量。对准视线的数量级估计可写为

\[E'\sim {E_{\rm obs}(1+z)\over \Gamma}\, .\]

这里 \(E_{\rm obs}\) 是观测到的光子能量，\(E'\) 是 outflow 共动系能量。由于成对产生阈值在共动系中判断，\(E'\) 降低会把所需目标光子推向更高能的谱尾，从而减少可吸收目标光子的数量。

第九步：共动系辐射能量密度也被降低。对各向同性等效 luminosity 的单区估计为

\[u'_{\gamma}\sim {L_{\rm iso}\over 4\pi R^2c\Gamma^2}\, .\]

其中 \(R^{-2}\) 来自更大的辐射半径，\(\Gamma^{-2}\) 来自 luminosity 与共动能量密度之间的相对论变换。由此可得目标光子数密度 \(n'_{\gamma}\sim u'_{\gamma}/\langle E'\rangle\)，这是计算相对论 \(\gamma\gamma\) 光深的输入。

第十步：把谱形放入目标光子计数。若高能端 photon number spectrum 可近似为 \(N(E)\propto E^{-\beta}\)，则对观测到的最高能光子 \(E_{\rm max}\)，目标光子阈值随 \(\Gamma\) 升高而上移，常见数量级依赖可写为

\[\tau_{\gamma\gamma}(E_{\rm max})\propto {L_{\rm iso}\over \delta t_{\rm obs}}E_{\rm max}^{\beta-1}\Gamma^{-(2eta+2)}\, .\]

不同论文会因谱指数定义、角分布、Doppler factor 和截面近似而有不同系数，但关键物理不变：\(\tau_{\gamma\gamma}\) 对 \(\Gamma\) 是高次幂敏感的。

第十一步：用透明条件定义可观测的最小 Lorentz factor。若最高能光子确实来自同一 prompt 辐射区，它能逃逸要求

\[\tau_{\gamma\gamma}(E_{\rm max},\Gamma_{\rm min})=1\, ,\qquad \tau_{\gamma\gamma}(E_{\rm max},\Gamma)<1\ \Rightarrow\ \Gamma>\Gamma_{\rm min}\, .\]

这一步把理论诊断量 \(\tau_{\gamma\gamma}\) 闭合到观测量 \(L_{\rm iso}\)、\(\delta t_{\rm obs}\)、\(E_{\rm max}\) 和谱指数 \(\beta\)。典型 MeV prompt emission 常给出 \(\Gamma_{\rm min}\sim 10^2\)，含 GeV 光子的事件可能要求更高的 \(\Gamma_{\rm min}\)。

第十二步：最后把透明性要求接到火球动力学。若中心引擎注入总能量 \(E_0\)，同时夹带重子质量 \(M_b\)，理想火球的最大可达 Lorentz factor 由重子载荷参数决定：

\[\eta={E_0\over M_bc^2}\, ,\qquad \Gamma\lesssim \eta\, .\]

因此 compactness 给出的 \(\Gamma\gtrsim 10^2\) 不只是辐射转移条件，也意味着 \(M_b\lesssim E_0/(10^2c^2)\)。这就是第一讲的核心闭合：短时标、高 luminosity、非热谱和最高能光子共同迫使 GRB 拥有超相对论 outflow，并同时要求火球中的重子污染足够低。

经典拟合 / 应用方法

本讲的拟合目标不是“证明某一种 prompt 辐射机制正确”，而是把观测数据转化为紧致性诊断所需的输入量。最基础的光谱模型通常是经验的 Band 函数或 cutoff power law。Band 函数的参数包括归一化 \(A\)、低能 photon index \(\alpha\)、高能 photon index \(\beta\) 和 \(\nu F_\nu\) 峰值能量 \(E_{\rm pk}\)。在本讲边界内，Band 函数只是一种压缩观测信息的工具：它告诉我们光子场的能量分布、目标光子数密度、高能尾是否足够丰富，以及最高能光子 \(E_{\rm max}\) 在这样的光子场中是否应被 \(\gamma\gamma\) 吸收。

实际读论文时，要特别注意光谱拟合应在 counts 空间完成，而不是直接对 unfolded spectrum 上的点做普通最小二乘。若 photon model 为 \(M(E;\boldsymbol{\theta})\)，仪器响应矩阵为 \(R_{ij}\)，曝光时间为 \(T\)，背景期望为 \(b_i\)，则第 \(i\) 个能道的模型计数为 \(\mu_i(\boldsymbol{\theta})=T\sum_j R_{ij}M(E_j;\boldsymbol{\theta})+b_i\)。低计数或高能端稀疏计数时，常用 Poisson likelihood 或 Cash statistic；只有在计数足够高且误差近似 Gaussian 时，\(\chi^2\) 才是合适近似。判断一篇论文的拟合是否可靠，第一步就是看它是否正确处理了响应、背景和计数统计。

紧致性问题的参数链条通常分为两层。第一层从光变曲线和时间分辨光谱得到 \(F_{\rm pk}\)、\(L_{\rm iso}\)、\(\delta t\)、\(E_{\rm pk}\)、\(\alpha\)、\(\beta\) 和 \(E_{\rm max}\)。第二层把这些量代入 \(\tau_{\gamma\gamma}(E_{\rm max},\Gamma)\)，并由 \(\tau_{\gamma\gamma}=1\) 得到 \(\Gamma_{\rm min}\)。严格做法不是只把最佳拟合值代入一个公式，而是把光谱参数、红移、峰值通量和时间窗选择的不确定性传播到 \(P(\Gamma_{\rm min}|{\rm data})\)。因此读到某个 \(\Gamma_{\rm min}\) 数值时，应把它理解为依赖模型假设的下限分布，而不是精确测量的单一常数。

\(\delta t\) 的测量是最容易被低估的拟合环节。本讲故意区分 \(T_{90}\) 与 \(\delta t\)：\(T_{90}\) 描述累计 \(90\%\) fluence 的持续时间，适合分类；\(\delta t\) 描述最窄且统计显著的源内结构，进入 \(R\sim 2\Gamma^2c\delta t/(1+z)\)。常见测量方法包括脉冲分解、结构函数、小波分析、Bayesian blocks 和最小显著变时标估计。读论文时应检查 binning 是否过粗、背景是否稳定、短尖峰是否跨能段同时存在、显著性是否经过 trials correction。由于 \(\Gamma_{\rm min}\) 通常随 \(L_{\rm iso}/\delta t\) 增大而增大，一个可疑的极短 \(\delta t\) 会人为推高 Lorentz factor 下限。

残差诊断要放在物理解释之前。Band 模型拟合后，应看 data/model ratio 是否在低能端、高能端、探测器能区交界或背景主导区出现系统性偏离。若高能端残差显示额外 power-law 成分，说明单一区 Band 高能尾可能不能代表真实目标光子场；若谱中存在 quasi-thermal 成分或指数 cutoff，则 \(\gamma\gamma\) 吸收所需的目标光子数也会改变。特别是 Fermi/LAT 事件中，GeV 光子常有延迟；如果 \(E_{\rm max}\) 与 MeV prompt 光子不共时，用它约束同一区域的 \(\Gamma\) 就可能过强。

系统误差主要来自五类来源。第一，红移未知时，\(d_L\)、\(E_{\rm iso}\) 和 \(L_{\rm iso}\) 都只能假设，\(\Gamma_{\rm min}\) 也随之成为条件性结果。第二，谱外推会影响高能目标光子数，尤其当 \(\beta\) 约束差或高能端只有少数计数时。第三，最高能光子的关联概率需要检查，背景 cosmic ray 或误分类事件会污染 \(E_{\rm max}\)。第四，不同时间窗会给出不同 \(L_{\rm iso}\)、\(\beta\) 和 \(E_{\rm max}\)，必须尽量使用物理上同一脉冲或同一辐射段。第五，多区辐射会破坏单区 compactness 假设；若 MeV 光子和 GeV 光子来自不同半径，单一 \(R\)、单一 \(\Gamma\) 和单一 \(\delta t\) 的解释就只是近似。

教学应用中，建议把拟合练习设计成“先经验、再诊断、最后质疑”的流程。给学生一条 prompt light curve、一组 Band 参数、一个红移和一个最高能光子，让他们先算 \(L_{\rm iso}\)、选取 \(\delta t\)，再估算 \(\Gamma_{\rm min}\)。随后让他们改变 \(\delta t\) 一倍、把 \(\beta\) 改变 \(0.2\)、或把 \(E_{\rm max}\) 移到不同时间窗，比较 \(\Gamma_{\rm min}\) 的变化。这样能直观看到：紧致性结论“必须相对论”非常稳健，但具体 \(Γ_{\rm min}\) 数值对数据处理和模型假设很敏感。

重点章节 / 结果段落怎么读

读 Klebesadel et al. \(1973\) 时，课程重点不是背诵“Vela 卫星发现了 GRB”，而是学习一篇发现论文如何建立信号真实性。应先看多颗卫星如何记录同一类短时标伽马闪光，再看作者如何排除地球、太阳活动和仪器伪信号。由于早期定位很差，论文并不能直接给出距离；它真正打开的问题是：这些短暂、高能、非重复或弱重复的瞬变究竟属于哪一个天体物理尺度。

读早期全天分布和亮度统计结果时，应把它们视为从发现走向宇宙学图像的中间桥梁。天空近似各向同性削弱了普通银河盘源解释，而 \(\log N-\log P\) 或 \(\log N-\log S\) 在暗端偏离简单欧氏期望，提示样本可能受到宇宙学几何、源演化、luminosity function 和探测阈值共同影响。这里要训练的是：角分布只能告诉我们“不像普通银河盘”，不能单独证明每个 GRB 的红移和能量。

读 Goodman \(1986\) 时，要抓住 compactness problem 的推理结构。第一，用短变时标 \(\delta t\) 得到静止源尺度 \(R\lesssim c\delta t/(1+z)\)。第二，用宇宙学 luminosity 得到极高光子数密度。第三，用 \(\gamma\gamma\rightarrow e^+e^-\) 得到 \(\tau_{\gamma\gamma}\gg 1\)。第四，指出这与观测到的透明非热 MeV 光谱矛盾。第五，引入相对论膨胀，使半径、共动能量和共动能量密度同时改变。读这一节时不要急于问 prompt 光子究竟由同步辐射还是光球产生；这篇经典工作的核心是证明“没有 relativistic outflow 就过不了透明性门槛”。

读 Paczynski、Rees 和 Mészáros 相关火球工作时，应把重点放在动力学闭合上。宇宙学距离把 \(E_{\rm iso}\) 和 \(L_{\rm iso}\) 推到极大值，compactness 要求 \(\Gamma\gtrsim 10^2\)，火球模型则解释中心引擎释放的能量如何转化为 bulk kinetic energy。若总能量为 \(E_0\)，重子质量为 \(M_b\)，则 \(\eta=E_0/(M_bc^2)\) 给出可达到的 Lorentz factor 标尺。这里的关键不是某个数值系数，而是理解透明性约束如何转化为重子污染约束。

读 Band et al. \(1993\) 和后续 prompt 光谱样本时，应把它们看作下一讲的入口。Band 函数不是最终物理机制，但它统一了 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\) 和 fluence 的测量语言。对本讲而言，高能谱指数 \(\beta\) 和最高能光子 \(E_{\rm max}\) 直接进入 \(\tau_{\gamma\gamma}\) 估算；对下一讲而言，\(\alpha\)、\(E_{\rm pk}\) 和谱演化将成为区分 synchrotron、photosphere 和 magnetic dissipation 的证据。

本讲建议的经典阅读练习是选择一个有红移、有 prompt 光谱、有高能光子的 Fermi GRB，列出 \(z\)、\(d_L\)、\(F_{\rm pk}\)、\(L_{\rm iso}\)、\(\delta t\)、\(E_{\rm pk}\)、\(\beta\) 和 \(E_{\rm max}\)。然后用一页纸回答三个问题：如果源静止，为什么 \(\tau_{\gamma\gamma}\gg 1\)；如果源以 \(\Gamma\gg 1\) 运动，哪三项相对论效应降低光深；最后，哪些观测选择最影响 \(\Gamma_{\rm min}\)。这能把历史论文、公式推导和现代数据分析连接起来。

建议重点查看的图表

一，GRB 全天分布图。检查坐标是否为 Galactic coordinates，重点看事件是否沿银河盘 \(b=0^\circ\) 集中。若点在天球上近似各向同性，说明普通银河盘源模型受压制；但不能把各向同性误读为所有事件距离相同。

二，\(\log N-\log P\) 或 \(\log N-\log S\) 图。检查亮源端是否接近欧氏均匀分布的 \(N(>P)\propto P^{-3/2}\)，暗端是否变平。重点同时看探测阈值、触发效率和 completeness，否则暗端偏离可能被仪器选择效应放大或伪造。

三，prompt light curve。检查横轴时间、纵轴 counts rate 或 energy flux、能段划分、背景区间、\(T_{90}\) 和最小显著变时标 \(\delta t\)。本讲用于 compactness 的不是总持续时间 \(T_{90}\)，而是最窄可信结构 \(\delta t\)。

四，时间分辨 Band spectrum 或 \(\nu F_\nu\) spectrum。检查 \(E_{\rm pk}\)、\(\alpha\)、\(\beta\)、高能尾、低能偏离和探测器交叉归一化。重点判断谱是否真正非热，以及高能端是否足够约束 \(\gamma\gamma\) 目标光子场。

五，残差或 data/model ratio 图。检查残差是否随机分布在零附近，还是在低能、高能或仪器边界处出现系统结构。系统残差意味着单一 Band 模型可能不足，从而影响 \(L_{\rm iso}\)、\(\beta\) 和 \(\Gamma_{\rm min}\) 的推断。

六，\(\tau_{\gamma\gamma}\) 随 \(\Gamma\) 的曲线。检查纵轴是否为 \(\tau_{\gamma\gamma}\)，横轴是否为 \(\Gamma\)，水平线 \(\tau_{\gamma\gamma}=1\) 与曲线交点就是 \(\Gamma_{\rm min}\)。重点比较不同 \(\delta t\)、\(E_{\rm max}\)、\(\beta\) 假设下交点如何移动。

七，Fermi/LAT 高能光子时间-能量图。检查 GeV 光子是否与 MeV prompt 脉冲共时、是否延迟、关联概率是否高。若最高能光子不属于同一辐射区，用它做单区 compactness 约束会有风险。

八，relativistic fireball 半径示意图。检查初始半径、加速区、coasting 区、photospheric radius 和可能耗散半径的相对顺序。本讲只要求读懂 \(R\sim 2\Gamma^2c\delta t/(1+z)\) 如何放宽源区尺度，不要求在图中判断具体 prompt 机制。

关键图表逐图导读

图一：全天分布图。横轴通常是 Galactic longitude，纵轴是 Galactic latitude，数据点代表 GRB 触发方向。读图时先看点是否沿 \(b=0^\circ\) 的银河盘集中，再看是否有明显偶极或四极各向异性。若没有银河盘集中，说明普通银河盘源难以解释。误读风险是把“角分布各向同性”直接等同于“宇宙学距离已被证明”；实际上它只是支持宇宙学或大尺度 halo 等解释，距离还需要亮度统计、余辉定位和红移确认。

图二：\(\log N-\log P\) 图。横轴是峰值通量 \(P\) 或 fluence \(S\)，纵轴是亮于阈值的累积数 \(N(>P)\)，通常采用双对数坐标。欧氏均匀空间的参考线斜率为 \(-3/2\)。读图时看亮源端是否接近该斜率、暗源端是否变平，同时检查触发阈值附近是否标出 completeness。常见误读是把暗端变平完全归因于宇宙学效应；实际上 luminosity function、源演化和探测效率也会改变斜率。

图三：prompt light curve。横轴是触发后观测时间，纵轴是 counts rate、photon flux 或 energy flux，不同颜色常表示不同能段。读图时要分别标出 \(T_{90}\) 和 \(\delta t\)：\(T_{90}\) 是总持续时间指标，\(\delta t\) 是 compactness 推导中的局部因果时标。数据点和误差条应与背景模型一起看，尤其要确认最窄峰不是背景涨落、死时间效应或过细 binning 的产物。误读风险是用 \(T_{90}\) 代替 \(\delta t\)，从而把源区半径估计得过大。

图四：\(\nu F_\nu\) spectrum 与 Band 拟合。横轴是 photon energy，纵轴常为 \(\nu F_\nu\) 或 \(E^2N(E)\)。模型线给出 Band 函数或 cutoff power law，数据点来自不同探测器。读图时先找 \(E_{\rm pk}\)，再看低能斜率 \(\alpha\) 和高能斜率 \(\beta\) 是否被数据真正约束，最后看高能端是否存在额外成分。误读风险是把 unfolded 点当作独立观测量；实际拟合是在 counts 空间完成，图上的 flux 点常依赖模型。

图五：光谱残差图。横轴与主谱图相同，纵轴可能是 (({
m data}-{
m model})/\(\sigma\)) 或 data/model ratio。理想情况下残差应在零附近随机散布；若在高能端连续偏正，可能存在额外 power-law 成分；若在低能端有弯曲，可能需要热成分或吸收校正；若在探测器拼接区跳变，可能是交叉定标问题。误读风险是只看总的 likelihood 或 \(\chi^2\) 可接受，却忽略局部系统残差对 \(\beta\) 和 \(\tau_{\gamma\gamma}\) 的影响。

图六：\(\tau_{\gamma\gamma}\) 对 \(\Gamma\) 的诊断图。横轴为 \(\Gamma\)，纵轴为 \(\tau_{\gamma\gamma}\)，通常双对数显示。水平线 \(\tau_{\gamma\gamma}=1\) 与模型曲线的交点定义 \(\Gamma_{\rm min}\)。若图中有多条曲线，应检查它们分别对应不同 \(\delta t\)、\(E_{\rm max}\)、\(L_{\rm iso}\) 或 \(\beta\)。误读风险是把交点当成真实 \(\Gamma\) 的测量值；它只是透明性下限，真实 \(\Gamma\) 可以更高。

图七：LAT 高能光子时间-能量图。横轴是触发后时间，纵轴是 photon energy，每个点代表一个候选高能光子，颜色或标记可能表示关联概率或事件等级。读图时要看 \(E_{\rm max}\) 是否落在明亮 MeV prompt 脉冲内，还是在 prompt 之后延迟出现。若最高能光子与 MeV 光子共时，单区 compactness 约束较直接；若显著延迟，它可能来自外激波或另一区域。误读风险是只取全事件最高能光子，却不检查它与目标光子场是否同时同区。

图八：相对论火球示意图。横轴通常为半径 \(R\)，纵轴可能画 \(\Gamma\)、温度、光深或只是示意结构。应识别初始半径、加速区、饱和半径、photospheric radius 和可能的耗散半径。模型线说明 \(\Gamma\) 如何从小半径加速到 coasting 阶段，并在光深降低后允许光子逃逸。本讲的结论只需要读出：相对论运动使观测短时标对应更大的 \(R\)，并降低共动系光子能量密度；不要把示意图中的每个半径都当成直接观测值。

后续阅读路径

第一条阅读路径是从发现到距离尺度。先读 Klebesadel et al. \(1973\) 的发现论文，学习早期 GRB 信号如何被确认以及为什么定位困难；再读 BATSE 时代的全天分布和 \(\log N-\log P\) 结果，理解各向同性和暗端偏离如何改变起源讨论；最后读 BeppoSAX 之后的余辉定位和红移观测，看到宇宙学距离如何把 \(E_{\rm iso}\) 与 \(L_{\rm iso}\) 推到现代 GRB 能量尺度。这一路径回答“我们为什么相信许多 GRB 是宇宙学爆发”。

第二条阅读路径是从 compactness 到相对论火球。以 Goodman \(1986\) 为核心，先掌握 \(\tau_{\gamma\gamma}\gg 1\) 的矛盾，再读 Paczynski、Shemi、Piran、Rees 和 Mészáros 关于 fireball expansion、baryon loading 和 relativistic outflow 的经典工作。重点放在 \(E_0\)、\(M_b\)、\(\eta\)、\(\Gamma\)、photosphere 和 transparency 之间的关系，而不是追求每个公式系数完全一致。不同论文的截面近似和角分布处理可能不同，但共同结论是 \(\Gamma\gg 1\) 不可避免。

第三条阅读路径是从经验光谱到 prompt 机制。Band et al. \(1993\) 是统一描述 prompt 谱形的入口；随后可读 BATSE、Swift 和 Fermi 的时间分辨谱统计，跟踪 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\) 和 luminosity 的演化。下一讲会在这个基础上比较 optically thin synchrotron、photospheric emission 和 magnetic dissipation。本讲不提前判定哪一种机制正确，只要求读者明白：任何机制都必须放在一个满足 \(\tau_{\gamma\gamma}<1\) 的相对论 outflow 中。

第四条阅读路径是从 Fermi/LAT 走向现代高能约束。含 GeV 光子的 GRB，尤其是具有高 \(E_{\rm max}\)、明亮 MeV prompt 和短 \(\delta t\) 的事件，可以给出更强的 \(\Gamma_{\rm min}\)。阅读这些论文时要特别看高能光子的到达时间、关联概率、是否存在额外 spectral component，以及作者采用的是单区还是多区解释。这一路径会自然引出后续关于 prompt 区域位置、外激波早期 GeV emission 和多成分辐射的讨论。

第五条阅读路径是通向多信使和结构化喷流。GRB \(170817A\) 之后，viewing angle、jet structure 和 off-axis emission 成为现代 GRB 研究的重要变量。它们会改变观测到的 \(L_{\rm iso}\)、\(E_{\rm iso}\) 和光变形状，也会影响我们如何把观测量映射到真实能量与喷流几何。但即使进入多信使时代，compactness problem 仍是底线检查：只要观测到快速、明亮、非热的伽马光子，就必须说明它们如何在相对论 outflow 中逃逸。

下一讲建议

同一系列第 \(2/6\) 讲最自然的方向是“prompt 光谱经验规律与辐射机制候选”。本讲已经建立 \(\Gamma\gg 1\) 的必要性，但故意没有展开 prompt 光子怎样产生；下一讲应系统讲 Band 函数、\(E_{\rm pk}\)、\(\alpha\)、\(\beta\)、hard-to-soft 演化、intensity tracking，以及 optically thin synchrotron、photospheric emission 和 magnetic reconnection 的第一轮比较。这样可以保持边界清楚：本讲解决透明性门槛，下一讲讨论辐射机制诊断。

第 \(3/6\) 讲可以进入“prompt 发射区的时空结构：内激波、磁重联、光球和耗散半径”。这部分应把 \(R\sim 2\Gamma^2c\delta t/(1+z)\)、photospheric radius、internal shock radius 和 magnetic dissipation radius 放到同一张半径图里，讨论效率、变时标和多区辐射。它与本讲相连，因为本讲只证明大 \(\Gamma\) 必要；第 \(3/6\) 讲才问能量在什么半径、通过什么机制耗散。

第 \(4/6\) 讲再进入 afterglow 外激波、Blandford-McKee 动力学和同步辐射 break。它不应过早混入本讲，因为 afterglow 主要诊断外部介质、冲击动力学和晚期多波段演化；本讲的重点是 prompt 阶段的 compactness。按这个顺序，学生会先理解为什么 GRB 必须相对论，再理解 prompt 谱如何产生，最后理解相对论 ejecta 如何被外部介质减速并形成余辉。
