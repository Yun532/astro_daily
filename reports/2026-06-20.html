经典工作详细讲解

本讲在《GRB 从零到前沿课程》的第 \(3/6\) 讲中承担一个承上启下的任务。第 \(1\) 讲已经说明 prompt 辐射区必须以 \(\Gamma\gg 1\) 相对论运动，否则毫秒到秒级变时标与巨大光度会导致严重的 \(\gamma\gamma\) 不透明性；第 \(2\) 讲已经建立了 Band 或 CPL 经验谱接口，使我们可以用 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\) 和通量描述观测光谱。本讲向前推进一步：既然喷流已经相对论透明，既然观测谱已经可参数化，那么喷流动能究竟在哪里、通过什么耗散机制、以什么粒子辐射过程转化为 prompt 光子？本讲只讨论低磁化、多壳层内激波和光学薄同步辐射，不展开光球、磁重联和外激波 afterglow。

历史动机来自 BATSE 时代形成的两个强约束。第一，许多 GRB prompt 光变呈现复杂尖峰，时间尺度从毫秒到数秒不等，像是在直接记录中心引擎的非稳态活动。第二，相对论火球若以单一 \(\Gamma\) 冷却滑行，并不会自动高效辐射；必须存在某种把有序 bulk kinetic energy 转化为内能的耗散机制。Rees 与 Meszaros 的非稳态壳层图像正好把这两点合在一起：中心引擎发出一串 Lorentz 因子不同的壳层，后发快壳追上先发慢壳，在喷流内部发生碰撞，形成前向冲击、反向冲击和接触间断。这样，引擎的短时标结构可以被保存到大半径，而不是被单一外部减速面完全抹平。

本讲的方法主线是从运动学到辐射谱的一条连续链。两壳层追赶首先给出内激波半径的数量级关系

\[R_{\rm is}\simeq \frac{2\Gamma^{2}c\delta t_{\rm obs}}{1+z}.\]

这个式子不是精确模型，而是本讲的时间—半径主线：观测变时标 \(\delta t_{\rm obs}\) 经过相对论 \(\Gamma^{2}\) 放大后，对应透明区外的大半径碰撞。随后，用一维完全非弹性碰撞近似和能量动量守恒估计合并后 Lorentz 因子与耗散效率，典型表达为

\[\eta_{\rm is}=1-\frac{\Gamma_f(m_1+m_2)}{m_1\Gamma_1+m_2\Gamma_2}.\]

这一步告诉我们，内激波效率对相邻壳层 Lorentz 因子反差和质量加载非常敏感；若速度太接近，碰撞虽然发生，能量耗散却很弱。

有了耗散半径和效率之后，课程进入辐射物理。低磁化假设意味着磁压不是喷流动力学主导项，冲击后内能用微物理参数 \(\epsilon_e\) 和 \(\epsilon_B\) 分别分配给非热电子和磁场。共动能量密度可估为

\[u'\simeq \frac{L_k}{4\pi R_{\rm is}^{2}\Gamma^{2}c},\]

磁场满足

\[\frac{B'^2}{8\pi}=\epsilon_B u'.\]

若电子注入分布为 \(dN_e/d\gamma_e\propto \gamma_e^{-p}\)，且 \(\gamma_e\ge \gamma_m\)，则同步辐射特征频率近似为

\[\nu_m\simeq \frac{\Gamma}{1+z}\frac{3q_eB'}{4\pi m_ec}\gamma_m^2,\]

并与观测峰值能量通过 \(E_{\rm pk}\sim h\nu_m\) 相连。这一链条使 \(\delta t_{\rm obs}\)、\(\Gamma\)、\(L_k\)、\(\epsilon_e\)、\(\epsilon_B\)、\(\gamma_m\) 和 \(E_{\rm pk}\) 不再是孤立概念，而是同一个 prompt 机制的不同投影。

关键张力来自冷却与低能谱指数。同步冷却时间为

\[t'_{\rm syn}(\gamma_e)=\frac{6\pi m_ec}{\sigma_TB'^2\gamma_e(1+Y)},\]

令 \(t'_{\rm syn}(\gamma_c)=t'_{\rm dyn}\) 得到

\[\gamma_c=\frac{6\pi m_ec}{\sigma_TB'^2t'_{\rm dyn}(1+Y)}.\]

若 \(\nu_c<\nu_m\)，电子处于快冷；若 \(\nu_c>\nu_m\)，电子处于慢冷。最简 prompt 条件下能量密度高，常自然落入快冷。标准薄同步辐射给出两个重要诊断基准：单电子低频极限 \(F_\nu\propto \nu^{1/3}\) 对应 \(\alpha=-2/3\)，而标准快冷区间 \(\nu_c<\nu<\nu_m\) 的 \(F_\nu\propto \nu^{-1/2}\) 对应 \(\alpha=-3/2\)。观测中大量时间分辨谱出现 \(\alpha\sim -1\)，甚至一部分达到 \(\alpha>-2/3\)，这就是 synchrotron line of death 的核心问题。

读论文时，本讲要求把这些公式转化为可检验诊断，而不是只问理论曲线是否“像 Band 谱”。经验拟合中应先从 counts space 得到 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\)、通量和拟合统计量；物理解释中再比较这些量是否与 \(R_{\rm is}\)、\(\eta_{\rm is}\)、\(\nu_m\)、\(\nu_c\) 和冷却状态一致。若使用计数似然，典型形式为

\[\ln{\cal L}=\sum_j\left[k_j\ln\mu_j(\theta)-\mu_j(\theta)-\ln(k_j!)\right],\]

其中 \(k_j\) 是观测计数，\(\mu_j(\theta)\) 是经过仪器响应折叠后的模型计数。若采用 Bayesian 分析，则应检查

\[p(\theta|D)\propto {\cal L}(D|\theta)\pi(\theta),\]

并确认先验没有人为决定快冷或慢冷结论。残差图同样关键：低能端连续同号偏离常指向低能斜率问题，峰附近波状残差可能说明谱宽不匹配，探测器交界处异常则可能来自响应或交叉定标。

图像阅读是本讲的另一条训练线。壳层追赶图要看快慢壳世界线交点如何随 \(\Gamma\) 和 \(\delta t\) 移动，不能把脉冲宽度直接当成源区尺寸；半径标尺图要检查 \(R_{\rm is}\) 是否位于 \(R_{\rm ph}\) 之外，否则薄同步辐射边界失效；效率图要比较 \(\eta_{\rm is}\) 与观测 prompt 辐射效率；电子分布与同步谱断裂图要区分快冷的 \(\nu_c<\nu_m\) 和慢冷的 \(\nu_c>\nu_m\)，并把 \(F_\nu\) 斜率正确转换为光子指数；\(\alpha\) 分布图要同时标出 \(\alpha=-2/3\) 与 \(\alpha=-3/2\)，判断挑战的是最简薄同步辐射硬度上限，还是标准快冷斜率；\(E_{\rm pk}\) 演化图要区分 hard-to-soft 与 intensity tracking；残差图则要定位模型失败发生在低能端、峰附近、高能统计不足区，还是仪器交界区域。

本讲的结论不是“同步辐射已经死亡”，而是“最简低磁化内激波加单区快冷薄同步辐射面临明确、可量化的压力”。内激波仍然重要，因为它定义了 prompt 研究中最常用的时间—半径关系、耗散效率语言和冷却谱诊断；但它也留下了效率偏低、快冷谱过软、部分 \(\alpha>-2/3\)、谱宽与时间演化不够灵活等问题。边缘快冷、衰减磁场、持续加速、多区叠加和逆康普顿冷却可以作为本讲点到的补救方向，但不在这里深入展开。第 \(4/6\) 讲将转向光球辐射、亚光球耗散和磁化喷流，比较它们如何回应低能谱、谱宽、效率和偏振等问题；afterglow 与 prompt-afterglow 能量预算则留给后续课程。

背景知识

GRB prompt 机制研究的起点并不是某一个优美的理论模型，而是一组很难同时满足的观测事实。BATSE 时代发现 GRB 在天空分布近似各向同性，支持宇宙学距离尺度；若距离为宇宙学尺度，各向同性等效能量常达到 \(10^{51}\) 到 \(10^{54}\,{\rm erg}\)。与此同时，prompt 光变包含毫秒到秒级的快速结构，若直接把变时标解释为静止源区尺寸 \(R\lesssim c\delta t\)，高能光子会在极高光子密度中通过 \(\gamma\gamma\) 湮灭而难以逃逸。第 \(1\) 讲已经说明，相对论 bulk motion 和较大的 \(\Gamma\) 可以缓解紧致性问题；本讲在这个基础上追问：透明之后，能量如何转化为辐射？

第 \(2\) 讲建立了经验谱接口。Band 函数或 CPL 可以把 prompt 谱压缩为低能指数 \(\alpha\)、高能指数 \(\beta\)、峰值能量 \(E_{\rm pk}\) 和归一化等参数。这个接口很重要，因为它让不同 burst、不同时间 bin 和不同仪器之间可以进行比较。但经验谱不是物理机制：\(\alpha\) 并不自己告诉我们电子如何加速，\(E_{\rm pk}\) 也不自己告诉我们磁场强度或辐射半径。本讲的历史任务，就是把这些经验参数重新接回喷流动力学和辐射物理。

内激波模型的历史吸引力来自 prompt 光变的复杂性。外激波当然可以把喷流动能转化为辐射，但一个相对平滑的外部减速面很难自然复制 prompt 阶段高度不规则、尖峰众多、脉冲间隔差异很大的光变。相反，如果中心引擎本身非稳态，发出许多 Lorentz 因子不同的壳层，那么快壳追上慢壳的碰撞时间和碰撞半径会保留引擎活动的时序信息。于是，\(\delta t_{\rm obs}\leftrightarrow R/(2\Gamma^2c)\) 这样的运动学关系就把观测光变、相对论运动和发射半径连接起来。

另一个背景是相对论火球本身需要耗散。一个已经完成加速并进入惯性滑行的冷喷流，如果所有壳层具有相同 \(\Gamma\)，就不会自动把大量 bulk kinetic energy 变成 MeV 光子。非稳态壳层内激波提供了一个最小耗散方案：相邻壳层之间的相对速度对应可用的有序动能，碰撞把其中一部分转化为随机内能，再经由电子和磁场辐射出去。这个方案不要求从一开始就假设光球热峰或磁重联结构，因此在早期 prompt 研究中非常自然。

同步辐射成为候选辐射机制也有清楚的物理原因。高能天体中，非热电子在磁场中辐射是最常见、最稳健的宽谱机制之一；冲击加速又常被用来产生 \(dN_e/d\gamma_e\propto \gamma_e^{-p}\) 的幂律电子分布。若冲击后电子获得比例 \(\epsilon_e\) 的内能，磁场获得比例 \(\epsilon_B\) 的内能，光学薄同步辐射就能自然产生非热谱和快速响应。也正因为它简单、通用，薄同步辐射成为 prompt 机制比较的基准模型。

但是，常见误区是把“内激波”和“Band 谱”直接画等号。内激波只说明能量在哪里耗散，不能保证谱形一定是 Band-like；同步辐射只说明电子如何辐射，不能保证低能指数自动等于观测值。真实谱形还取决于电子冷却、磁场演化、持续加速、逆康普顿冷却、多区叠加、曲率效应、探测器能段和时间积分。因此，本讲会反复强调：判断模型不能只看一条理论曲线穿过通量点，而要检查 \(\alpha\)、\(E_{\rm pk}\)、谱宽、效率、时间演化和残差结构是否同时自洽。

另一个常见误区是把 \(R_{\rm is}\sim 2\Gamma^2c\delta t\) 当作精确半径定律。它更准确地说是一个数量级运动学桥梁，依赖于壳层发射间隔、壳层厚度、\(\Gamma_2/\Gamma_1\)、红移 \(z\) 和观测时间 bin 定义。若 \(\delta t_{\rm obs}\) 来自角时间、冷却时间、冲击穿越时间或多个脉冲叠加，物理解释会不同。读论文时应先问作者如何定义变时标，再问所推得的 \(R_{\rm is}\) 是否位于光球半径 \(R_{\rm ph}\) 之外；若 \(R_{\rm is}

最重要的历史张力是低能谱指数。薄同步辐射的单电子低频极限给 \(F_\nu\propto \nu^{1/3}\)，对应光子数谱 \(N_E\propto E^\alpha\) 中的 \(\alpha=-2/3\)。标准快冷同步辐射在 \(\nu_c<\nu<\nu_m\) 区间给 \(F_\nu\propto \nu^{-1/2}\)，对应 \(\alpha=-3/2\)。然而 BATSE 和 Fermi 的时间分辨谱常见 \(\alpha\sim -1\)，并有部分谱硬于 \(\alpha=-2/3\)。这不是一个细枝末节的拟合问题，而是把经验谱参数转化为辐射机制判据的经典案例。

因此，本讲的重要性不在于宣称内激波同步辐射是唯一正确模型，也不在于简单否定它，而在于建立 prompt 机制比较的标准语言。后续讨论光球辐射、亚光球 Compton 化、磁化喷流、磁重联、多区同步辐射或边缘快冷时，都必须回答本讲提出的问题：发射半径是多少？变时标如何产生？效率是否足够？电子冷却状态是什么？\(\alpha\) 是否越过 \(\alpha=-2/3\) 或偏离 \(\alpha=-3/2\)？这些问题构成从经典内激波走向前沿 prompt 模型的共同坐标系。

基础理论 / 方法脉络

第一层基础图像是非稳态相对论壳层。中心引擎在活动时间 \(T\) 内不是连续喷出完全相同的流，而是发出许多具有不同质量、宽度、发射时刻和 Lorentz 因子的壳层。设先发慢壳的 Lorentz 因子为 \(\Gamma_1\)，后发快壳的 Lorentz 因子为 \(\Gamma_2\)，且 \(\Gamma_2>\Gamma_1\gg 1\)。在实验室系中，快壳追上慢壳的几何条件可写为 \(\beta_2ct=\beta_1ct+c\delta t_{\rm eng}\)。由于 \(\beta\simeq 1-1/(2\Gamma^2)\)，两条壳层世界线虽然几乎平行，但仍会在大半径相交；这就是短引擎时标能够对应大半径 prompt 发射的运动学原因。

第二层基础图像是内激波半径。若相邻壳层 Lorentz 因子差异不是极小，追赶半径可写成数量级形式

\[R_{\rm is}\simeq \frac{2\Gamma^2c\delta t_{\rm obs}}{1+z}.\]

这条关系是本讲贯穿始终的时间—半径桥梁。它说明观测变时标 \(\delta t_{\rm obs}\) 不应被直接解释为静止源区尺寸 \(c\delta t_{\rm obs}\)，而要考虑相对论角时间和 Doppler 压缩。读论文时应同时检查 \(R_{\rm is}\) 与光球半径 \(R_{\rm ph}\) 的相对位置；本讲只在 \(R_{\rm is}\) 位于透明区外时讨论光学薄同步辐射，不推导光球物理。

第三层基础图像是低磁化冲击耗散。快壳追上慢壳后，会形成前向冲击、反向冲击和接触间断；在入门层面，可以先把它近似为一维完全非弹性合并。碰撞前的总能量为 \(E_i=(m_1\Gamma_1+m_2\Gamma_2)c^2\)，总动量为 \(P_i=(m_1\Gamma_1\beta_1+m_2\Gamma_2\beta_2)c\)。能量动量守恒决定合并后 Lorentz 因子 \(\Gamma_f\) 和产生的内能。相应内激波效率可写为

\[\eta_{\rm is}=1-\frac{\Gamma_f(m_1+m_2)}{m_1\Gamma_1+m_2\Gamma_2}.\]

这说明内激波不是天然高效机制：若 \(\Gamma_2/\Gamma_1\) 接近 \(1\)，耗散效率很低；若反差很大，效率可提高，但会牵涉质量加载、光变和剩余动能约束。

第四层基础图像是冲击后能量分配。低磁化假设意味着磁场不是喷流动力学的主要承载者，耗散主要来自相邻壳层的相对 bulk kinetic energy。冲击后的共动能量密度常估为

\[u'\simeq \frac{L_k}{4\pi R_{\rm is}^{2}\Gamma^{2}c},\]

其中 \(L_k\) 是各向同性等效动能光度。磁场用微物理参数 \(\epsilon_B\) 表示：

\[\frac{B'^2}{8\pi}=\epsilon_Bu'.\]

非热电子用 \(\epsilon_e\) 和幂律注入描述，常写为 \(dN_e/d\gamma_e\propto \gamma_e^{-p}\)，且 \(\gamma_e\ge \gamma_m\)。这些参数不是第一性原理严格预测，而是把等离子体微物理压缩成可观测约束的桥梁。

第五层基础图像是同步辐射峰。一个 Lorentz 因子为 \(\gamma_e\) 的电子在共动磁场 \(B'\) 中辐射，特征频率随 \(B'\gamma_e^2\) 增大；再乘上 bulk Doppler boost 并除以红移因子，最小注入电子对应的观测频率为

\[\nu_m\simeq \frac{\Gamma}{1+z}\frac{3q_eB'}{4\pi m_ec}\gamma_m^2.\]

若谱峰由注入断裂主导，则 \(E_{\rm pk}\sim h\nu_m\)。这一步把宏观量 \(R_{\rm is}\)、\(\Gamma\)、\(L_k\) 与微观量 \(\epsilon_e\)、\(\epsilon_B\)、\(\gamma_m\) 连接到可观测的 \(E_{\rm pk}\)。因此，\(E_{\rm pk}\) 不只是经验拟合峰值，而是内激波同步辐射模型中非常敏感的物理诊断。

第六层基础图像是冷却状态。同步冷却时间为

\[t'_{\rm syn}(\gamma_e)=\frac{6\pi m_ec}{\sigma_TB'^2\gamma_e(1+Y)},\]

其中 \(Y\) 表示逆康普顿冷却对总冷却率的贡献。共动动力学时间可估为 \(t'_{\rm dyn}\simeq R_{\rm is}/(\Gamma c)\)，令 \(t'_{\rm syn}(\gamma_c)=t'_{\rm dyn}\) 可得到冷却 Lorentz 因子

\[\gamma_c=\frac{6\pi m_ec}{\sigma_TB'^2t'_{\rm dyn}(1+Y)}.\]

相应冷却频率为

\[\nu_c\simeq \frac{\Gamma}{1+z}\frac{3q_eB'}{4\pi m_ec}\gamma_c^2.\]

若 \(\nu_c<\nu_m\)，称为快冷；若 \(\nu_c>\nu_m\)，称为慢冷。GRB prompt 中能量密度高，最简估计往往容易进入快冷区，这直接决定低能谱斜率。

第七层基础图像是从 \(F_\nu\) 斜率到光子指数的转换。若 \(F_\nu\propto \nu^s\)，则光子数谱 \(N_E\propto E^\alpha\) 满足 \(\alpha=s-1\)。光学薄同步辐射的单电子低频极限给 \(F_\nu\propto \nu^{1/3}\)，因此 \(\alpha=-2/3\)；标准快冷在 \(\nu_c<\nu<\nu_m\) 区间给 \(F_\nu\propto \nu^{-1/2}\)，因此 \(\alpha=-3/2\)。这两条线是本讲最重要的诊断基准：\(\alpha>-2/3\) 挑战最简薄同步辐射硬度上限，\(\alpha\sim -1\) 或 \(\alpha>-3/2\) 挑战标准快冷，但不必立即否定所有改造后的同步辐射模型。

第八层基础图像是观测与边界。我们不能直接观测 \(B'\)、\(\gamma_m\)、\(\gamma_c\) 或 \(\eta_{\rm is}\)，而是通过时间分辨谱中的 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\)、通量、脉冲宽度和演化模式来反推。实际拟合应在 counts space 中完成，把理论谱经仪器响应矩阵折叠后与计数比较，并用残差、置信区间和系统误差检验模型。本讲故意止步于低磁化内激波、薄同步辐射和 line of death：光球辐射、亚光球耗散、磁化喷流、磁重联、偏振诊断以及 afterglow 能量预算都留到后续课程。这样划清边界后，学生才能把本讲当作 prompt 机制比较的基准模型，而不是把所有 GRB 辐射问题混在一起。

公式与推导

第一步：先把中心引擎的非稳态写成两壳层追赶问题。假设慢壳先以 \(\Gamma_{1}\) 发出，快壳后以 \(\Gamma_{2}\) 发出，且满足 \(\Gamma_{2}>\Gamma_{1}\gg 1\)，两次发射在引擎系相隔 \(\delta t_{\rm eng}\)，暂忽略壳层厚度。实验室系中的追赶条件是

\[\beta_{2}ct=\beta_{1}ct+c\delta t_{\rm eng}.\]

这一步要求解的是碰撞时间 \(t\)，物理含义是把观测到的快速光变追溯为快慢壳层的几何追赶；下一步用超相对论速度近似把它转成碰撞半径。

第二步：使用 \(\beta\simeq 1-1/(2\Gamma^{2})\)，并假设两壳层都已经处于惯性滑行阶段，可得

\[t_{\rm col}\simeq {\delta t_{\rm eng}\over \beta_{2}-\beta_{1}}\simeq {2\Gamma_{1}^{2}\delta t_{\rm eng}\over 1-\Gamma_{1}^{2}/\Gamma_{2}^{2}}.\]

这里求出的 \(t_{\rm col}\) 说明：即使 \(\beta_{2}\) 与 \(\beta_{1}\) 只差很小，追赶也会被 \(\Gamma^{2}\) 因子放大到大半径；下一步把 \(t_{\rm col}\) 乘以速度并加入红移修正。

第三步：若相邻壳层的 Lorentz 因子反差不是极小，可用代表性 bulk Lorentz factor \(\Gamma\) 写出内激波半径

\[R_{\rm is}\simeq {2\Gamma^{2}c\delta t_{\rm obs}\over 1+z}.\]

这里 \(\delta t_{\rm obs}\) 是观测变时标，\(z\) 是红移。这个式子是本讲的时间—半径主线：它告诉我们不要把 \(\delta t_{\rm obs}\) 直接解释为静止源区尺寸，而应把它转化为相对论喷流中的发射半径。得到 \(R_{\rm is}\) 后，下一步要问碰撞能耗散多少 bulk kinetic energy。

第四步：把快慢壳层近似为一维完全非弹性碰撞，初始静质量分别为 \(m_{1}\) 与 \(m_{2}\)，并先忽略辐射即时带走的能量。碰撞前总能量和总动量为

\[E_{\rm i}=(m_{1}\Gamma_{1}+m_{2}\Gamma_{2})c^{2},\qquad P_{\rm i}=(m_{1}\Gamma_{1}\beta_{1}+m_{2}\Gamma_{2}\beta_{2})c.\]

这一步求的是碰撞前四动量，它决定合并系统的不变量质量和最终 bulk motion；下一步用四动量不变量求 \(\Gamma_{\rm f}\) 与内激波效率。

第五步：总四动量守恒给出合并系统的不变量质量 \(M\) 与合并后 Lorentz 因子 \(\Gamma_{\rm f}\)：

\[M^{2}c^{4}=E_{\rm i}^{2}-P_{\rm i}^{2}c^{2},\qquad \Gamma_{\rm f}={E_{\rm i}\over Mc^{2}},\qquad \eta_{\rm is}=1-{\Gamma_{\rm f}(m_{1}+m_{2})\over m_{1}\Gamma_{1}+m_{2}\Gamma_{2}}.\]

其中 \(\eta_{\rm is}\) 是碰撞前 bulk kinetic energy 中被转化为内能的比例。若 \(\Gamma_{2}/\Gamma_{1}\) 接近 \(1\)，则 \(\eta_{\rm is}\) 很低；若反差较大，效率提高但会受到质量加载和剩余动能约束。下一步把可用内能转化为共动能量密度。

第六步：假设喷流在 \(R_{\rm is}\) 附近的各向同性等效动能光度为 \(L_{\rm k}\)，发射区以 \(\Gamma\) 运动，则共动能量密度数量级为

\[u'\simeq {L_{\rm k}\over 4\pi R_{\rm is}^{2}\Gamma^{2}c}.\]

这里的 \(u'\) 是冲击后粒子和磁场可分享的能量池。它把宏观量 \(L_{\rm k}\)、\(R_{\rm is}\) 与 \(\Gamma\) 接到辐射区局域物理；下一步用 \(\epsilon_{B}\) 估计共动磁场。

第七步：在低磁化内激波图像中，磁场不是动力学主导项，而是用微物理参数 \(\epsilon_{B}\) 表示冲击后内能中的磁场占比：

\[{B'^{2}\over 8\pi}=\epsilon_{B}u',\qquad B'\simeq \left({2\epsilon_{B}L_{\rm k}\over R_{\rm is}^{2}\Gamma^{2}c}\right)^{1/2}.\]

这一步求出同步辐射所需的共动磁场 \(B'\)。由于 \(B'\) 随 \(R_{\rm is}^{-1}\) 下降，观测变时标会通过 \(R_{\rm is}\) 强烈影响谱峰；下一步估计发光电子的最小 Lorentz 因子。

第八步：假设电子获得比例 \(\epsilon_{e}\) 的内能，并被注入为 \(dN_{e}/d\gamma_{e}\propto \gamma_{e}^{-p}\) 的幂律分布，且 \(p>2\)，则最小电子 Lorentz 因子可写为

\[\gamma_{m}\simeq \epsilon_{e}{p-2\over p-1}{m_{p}\over m_{e}}(\Gamma_{\rm rel}-1).\]

其中 \(\Gamma_{\rm rel}\) 表示冲击相对强度。这里求出的 \(\gamma_{m}\) 决定注入电子的典型同步辐射频率；下一步把 \(B'\)、\(\gamma_{m}\) 与 \(\Gamma\) 连接到观测的 \(E_{\rm pk}\)。

第九步：对以 \(\Gamma\) 指向观测者运动的发射区，同步辐射注入频率经 Doppler boosting 和红移修正后为

\[\nu_{m}\simeq {\Gamma\over 1+z}{3q_{e}B'\over 4\pi m_{e}c}\gamma_{m}^{2},\qquad E_{\rm pk}\sim h\nu_{m}.\]

若 \(\nu F_{\nu}\) 峰主要由注入断裂控制，则 \(E_{\rm pk}\) 可近似对应 \(h\nu_{m}\)。这说明 \(E_{\rm pk}\) 不是单独的经验参数，而是同时诊断 \(R_{\rm is}\)、\(\Gamma\)、\(\epsilon_{B}\)、\(\epsilon_{e}\) 与冲击强度；下一步判断电子是否在动力学时间内冷却。

第十步：假设电子主要通过同步辐射冷却，并允许逆康普顿冷却用 \(Y\) 增强总冷却率。共动同步冷却时间与动力学时间为

\[t'_{\rm syn}(\gamma_{e})={6\pi m_{e}c\over \sigma_{T}B'^{2}\gamma_{e}(1+Y)},\qquad t'_{\rm dyn}\simeq {R_{\rm is}\over \Gamma c},\qquad \gamma_{c}={6\pi m_{e}c\over \sigma_{T}B'^{2}t'_{\rm dyn}(1+Y)}.\]

这里 \(\gamma_{c}\) 由 \(t'_{\rm syn}(\gamma_{c})=t'_{\rm dyn}\) 定义，表示恰好能在发射区寿命内显著冷却的电子能量。下一步把 \(\gamma_{c}\) 转化为冷却频率并区分快冷与慢冷。

第十一步：冷却频率与冷却状态由

\[\nu_{c}\simeq {\Gamma\over 1+z}{3q_{e}B'\over 4\pi m_{e}c}\gamma_{c}^{2},\qquad \nu_{c}<\nu_{m}\ { m 为快冷},\qquad \nu_{c}>\nu_{m}\ { m 为慢冷}.\]

在最简 GRB prompt 参数下，较大的 \(u'\) 与 \(B'\) 往往使 (
\(\gamma_{c}\)) 偏低，从而容易进入快冷区。冷却状态直接决定低能谱斜率；最后一步把理论的 \(F_{\nu}\) 斜率转换为观测的光子指数。

第十二步：若发射区在相关能段光学薄，并且单区同步辐射近似成立，则斜率诊断为

\[F_{\nu}\propto \nu^{1/3}\Rightarrow \alpha=-{2\over 3},\qquad F_{\nu}\propto \nu^{-1/2}\Rightarrow \alpha=-{3\over 2},\qquad F_{\nu}\propto \nu^{-p/2}\Rightarrow \beta=-{p\over 2}-1.\]

第一项是单电子低频极限，对应最简薄同步辐射的硬度上限；第二项是标准快冷区间 \(\nu_{c}<\nu<\nu_{m}\) 的低能斜率；第三项把高能光子指数与电子谱指数 \(p\) 相连。因此，若时间分辨谱中大量出现 \(\alpha\sim -1\)，就挑战标准快冷；若出现稳健的 \(\alpha>-2/3\)，就挑战最简光学薄同步辐射本身。这正是本讲连接内激波模型、薄同步辐射和 synchrotron line of death 的观测闭合关系。

经典拟合 / 应用方法

第一步要把经验谱拟合当作“观测接口”，而不是当作物理答案。第 \(2/6\) 讲已经说明 Band 与 CPL 如何用 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\) 和归一化描述 prompt 谱；本讲继续使用这些量，但目标变成检验低磁化内激波与光学薄同步辐射。实际读论文时，应先确认每个时间 bin 是否在探测器计数空间拟合，而不是直接拟合去卷积后的通量点。经验拟合至少要记录 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\)、能量通量、时间 bin 范围、背景模型和拟合统计量。随后才把 \(\alpha\) 与 \(\alpha=-2/3\)、\(\alpha=-3/2\) 比较，把 \(E_{\rm pk}\) 与同步辐射断裂频率联系起来。

第二步是建立物理模板的层级。最浅层的同步辐射模板可直接用 \(p\)、\(\nu_m\)、\(\nu_c\)、峰值通量和归一化描述，其中 \(p\) 控制高能电子分布，\(\nu_m\) 与注入电子 \(\gamma_m\) 相关，\(\nu_c\) 与冷却电子 \(\gamma_c\) 相关。更深一层的物理模板把这些谱参数替换为 \(L_k\)、\(R_{\rm is}\)、\(\Gamma\)、\(\epsilon_e\)、\(\epsilon_B\)、\(Y\) 和红移 \(z\)，并通过 \(R_{\rm is}\simeq 2\Gamma^2c\delta t_{\rm obs}/(1+z)\)、\(u'\simeq L_k/(4\pi R_{\rm is}^2\Gamma^2c)\)、\(B'^2/(8\pi)=\epsilon_Bu'\) 推出谱断裂。浅层模板更适合稳健诊断，深层模板更接近内激波物理，但参数退化更强。

第三步是写清楚似然函数。若第 \(j\) 个能道观测到 \(k_j\) 个计数，模型谱经过有效面积、能量弥散、曝光时间和响应矩阵折叠后给出期望计数 \(\mu_j(\theta)\)，可使用 Poisson 形式

\[\ln {\cal L}(\theta)=\sum_j\left[k_j\ln \mu_j(\theta)-\mu_j(\theta)-\ln(k_j!)\right].\]

这里 \(\theta\) 不只包含光谱参数，也应包含背景归一化、探测器交叉定标和可能的系统误差项。若数据量很高，可在适当近似下使用高斯形式或常见高能谱统计量，但论文必须说明近似条件。最重要的原则是：理论谱必须先折叠到 counts space，不能把 unfolded flux 点当成彼此独立的高斯观测量后直接画线拟合。

第四步是解释后验和不确定度。Bayesian 分析通常写成

\[p(\theta|D)\propto {\cal L}(D|\theta)\pi(\theta),\]

其中 \(\pi(\theta)\) 是先验。读论文时要检查先验是否强行决定了物理结论。例如，对 \(\epsilon_B\)、\(\Gamma\)、\(Y\) 或 \(\gamma_c\) 采用很窄先验，可能人为固定 \(\nu_c<\nu_m\) 或 \(\nu_c>\nu_m\)；对 \(p\) 的先验也会影响 \(\beta=-p/2-1\) 的解释。若作者只报告最佳拟合值而不报告置信区间、posterior covariance 或 profile likelihood，就很难判断 \(\alpha\) 越过 \(\alpha=-2/3\) 是否真的显著。

第五步是设置模型比较的基准线。Band 或 CPL 是经验基准，单区快冷同步辐射是最简物理基准，边缘快冷、衰减磁场、持续加速或多区叠加是扩展同步辐射模型。比较模型时不能只看 \(\Delta \chi^2\)、\(\Delta \ln {\cal L}\)、AIC、BIC 或 Bayes factor，还要看参数是否自然，是否同时满足 \(E_{\rm pk}\)、\(R_{\rm is}\)、效率和变时标约束。若一个模型通过极端小的 \(\epsilon_B\) 或极端大的 \(\gamma_m\) 才拟合成功，它在统计上可行但在物理上可能并不令人满意。

第六步是做残差诊断。低能端连续同号残差通常说明低能斜率不对，正是检验 \(\alpha=-2/3\) 与 \(\alpha=-3/2\) 的关键位置；\(E_{\rm pk}\) 附近的波状残差说明谱峰宽度不匹配，可能区分 Band、同步辐射和多温光球；高能端残差则常受计数不足、背景和额外成分影响。若异常只出现在探测器交界能段，应优先怀疑响应矩阵、有效面积或交叉定标，而不是立刻宣称发现了新的辐射机制。

第七步是检查时间分辨稳健性。内激波图像强调中心引擎非稳态，因此时间 bin 的选择会直接改变物理解释。读论文时应比较 time-integrated 与 time-resolved 结果，检查单脉冲上升相和下降相是否分开拟合，并测试 bin 宽度变化后 \(\alpha\)、\(E_{\rm pk}\) 和通量相关是否稳定。多个脉冲叠加会展宽谱峰，也可能使 \(\alpha\) 变软或掩盖短时硬谱，因此不能用整个 burst 的积分谱直接代表一个单区内激波。

第八步是把拟合结果反推回喷流诊断。若 \(E_{\rm pk}\sim h\nu_m\)，则 \(E_{\rm pk}\) 对 \(B'\)、\(\gamma_m\)、\(\Gamma\) 和 \(R_{\rm is}\) 高度敏感；若 \(\nu_c<\nu_m\)，则快冷预言 \(\alpha=-3/2\)；若观测为 \(\alpha\sim -1\)，就需要边缘快冷或磁场衰减等修正；若稳健得到 \(\alpha>-2/3\)，则最简光学薄同步辐射本身受到挑战。好的模型拟合不是曲线穿过数据点，而是同时满足 counts-space 统计、残差形状、系统误差、时间演化、能量效率和物理参数数量级一致性。

重点章节 / 结果段落怎么读

读 Rees 与 Meszaros 的非稳态壳层内激波图像时，首先要抓住它回答的问题边界：它不是完整的 prompt 辐射理论，而是说明相对论喷流在透明区外如何把一部分 bulk kinetic energy 转成内能。第 \(1/6\) 讲已经告诉我们 \(\Gamma\gg 1\) 可以缓解紧致性问题，但没有说明能量在哪里耗散；第 \(2/6\) 讲已经提供 \(\alpha\)、\(\beta\)、\(E_{\rm pk}\) 的经验谱接口，但没有给出辐射机制。本讲读经典工作时，应把壳层追赶、内激波半径、耗散效率和同步辐射斜率连成一条链。

经典内激波段落的核心是两壳层运动学。读到慢壳先发、快壳后发时，要立刻写下追赶条件 \(\beta_2ct=\beta_1ct+c\delta t_{\rm eng}\)，再用 \(\beta\simeq 1-1/(2\Gamma^2)\) 理解为什么短的引擎时标会被放大为大的碰撞半径。关键式是 \(R_{\rm is}\simeq 2\Gamma^2c\delta t_{\rm obs}/(1+z)\)。读这一段时不要把它当成精确半径定律，而要当成时间—半径转换规则：它依赖 \(\Gamma_2/\Gamma_1\)、壳层厚度、红移 \(z\) 和变时标定义。

读效率段落时，要把两壳层碰撞看成一维非弹性碰撞的最低阶近似。碰撞前总能量和总动量决定合并后 \(\Gamma_f\) 以及耗散效率 \(\eta_{\rm is}=1-\Gamma_f(m_1+m_2)/(m_1\Gamma_1+m_2\Gamma_2)\)。这一段的教学重点不是背公式，而是看出内激波效率由 Lorentz 因子反差和质量加载控制。若 \(\Gamma_2/\Gamma_1\) 太接近 \(1\)，碰撞虽然发生但耗散很弱；若反差很大，效率提高，却可能引入光变、重子加载和剩余动能方面的新限制。

读同步辐射段落时，要按宏观到微观的顺序检查。先用 \(u'\simeq L_k/(4\pi R_{\rm is}^2\Gamma^2c)\) 估计共动能量密度，再用 \(B'^2/(8\pi)=\epsilon_Bu'\) 得到磁场，再用 \(dN_e/d\gamma_e\propto \gamma_e^{-p}\) 和 \(\gamma_e\ge \gamma_m\) 描述非热电子，最后用 \(\nu_m\simeq [\Gamma/(1+z)](3q_eB'/(4\pi m_ec))\gamma_m^2\) 连接到 \(E_{\rm pk}\sim h\nu_m\)。读这一段时要意识到 \(\epsilon_e\)、\(\epsilon_B\) 和 \(p\) 是微物理参数化，不是由内激波模型自动预言的常数。

读冷却与 line of death 段落时，必须分清两个不同基准。冷却时间 \(t'_{\rm syn}=6\pi m_ec/[\sigma_TB'^2\gamma_e(1+Y)]\) 与动力学时间比较给出 \(\gamma_c\) 和 \(\nu_c\)。若 \(\nu_c<\nu_m\)，标准快冷在 \(\nu_c<\nu<\nu_m\) 给出 \(F_\nu\propto \nu^{-1/2}\)，即 \(\alpha=-3/2\)；光学薄同步辐射的单电子低频极限给出 \(F_\nu\propto \nu^{1/3}\)，即 \(\alpha=-2/3\)。因此，\(\alpha>-3/2\) 主要挑战标准快冷，\(\alpha>-2/3\) 才挑战最简薄同步辐射硬度上限。

读 BATSE 或 Fermi 的低能谱指数统计时，要避免口号式理解“同步辐射死亡”。正确读法是逐层问：时间分辨谱是否足够窄？低能能段是否覆盖 \(E_{\rm pk}\) 以下足够范围？\(\alpha\) 的误差条是否跨过 \(\alpha=-2/3\) 或 \(\alpha=-3/2\)？使用 Band、CPL 或物理模板会不会改变结论？若大量谱集中在 \(\alpha\sim -1\)，它们确实挑战标准快冷，但可能由边缘快冷、衰减磁场、持续加速或多区叠加解释；若稳健硬于 \(\alpha=-2/3\)，问题更严重。

读现代修正同步辐射模型时，应检查作者解决的是哪一层张力。边缘快冷模型通常试图让 \(\nu_c\) 接近 \(\nu_m\)，从而避免长频段的 \(\alpha=-3/2\)；衰减磁场模型通过让电子在变弱的 \(B'\) 中冷却来硬化低能谱；持续加速或 slow heating 模型通过改变稳态电子分布来改变 \(F_\nu\) 斜率。读这些段落时必须继续追问 \(E_{\rm pk}\)、效率 \(\eta_{\rm is}\)、变时标 \(\delta t_{\rm obs}\) 和参数自然性，而不是只看 \(\alpha\) 是否变硬。

本讲的推荐阅读方式是做一张“从经典工作到观测诊断”的表：第一列写壳层追赶与 \(R_{\rm is}\)，第二列写内激波效率 \(\eta_{\rm is}\)，第三列写 \(\nu_m\)、\(\nu_c\) 和冷却状态，第四列写观测 \(\alpha\)、\(E_{\rm pk}\) 与残差。这样读论文，才能把经典内激波图像读成一个可检验的物理模型，而不是把它当作历史名词。

二，半径标尺图：横轴为对数半径 \(R\)，标出中心引擎、光球半径 \(R_{\rm ph}\)、内激波半径 \(R_{\rm is}\) 和外激波减速半径 \(R_{\rm dec}\)；本讲只用来判断 \(R_{\rm is}>R_{\rm ph}\) 时光学薄同步辐射是否自洽。

三，内激波效率图：横轴可为 \(\Gamma_2/\Gamma_1\)、壳层质量比或 Lorentz 因子方差，纵轴为 \(\eta_{\rm is}\)；应检查速度反差小时效率低、反差大时效率提高，以及是否能接近观测 prompt 辐射效率。

五，电子分布与同步辐射断裂图：上半图画 \(N(\gamma_e)\)，下半图画 \(F_\nu\)、\(\nu F_\nu\) 或 \(E^2N_E\)；必须标出 \(\gamma_c\)、\(\gamma_m\)、\(\nu_c\)、\(\nu_m\)，并区分 \(\nu_c<\nu_m\) 与 \(\nu_c>\nu_m\)。

六，低能谱指数 \(\alpha\) 分布图：横轴为 \(\alpha\)，纵轴为谱数、概率密度或 posterior density；必须叠加 \(\alpha=-2/3\) 与 \(\alpha=-3/2\) 两条基准线，并检查误差条、时间分辨选择和模型依赖。

七，\(E_{\rm pk}\)-通量或 \(E_{\rm pk}\)-时间演化图：横轴可为时间 \(t\)、能量通量或光子通量，纵轴为 \(E_{\rm pk}\)；应区分 hard-to-soft 与 intensity tracking，并避免仅凭相关性判断内激波成立。

八，counts-space 残差图：横轴为能量道或重建能量 \(E\)，纵轴为标准化残差；应比较 Band、CPL 和同步辐射模板在低能端、\(E_{\rm pk}\) 附近、高能端和探测器交界处的系统偏离。

图七：\(E_{\rm pk}\) 与通量演化图。横轴可以是时间 \(t\)、能量通量或光子通量，纵轴为 \(E_{\rm pk}\)。若 \(E_{\rm pk}\) 随脉冲相位整体下降，称为 hard-to-soft；若 \(E_{\rm pk}\) 与通量同升同降，称为 intensity tracking。内激波多碰撞可以产生复杂演化，曲率效应也会导致软化，因此数据点是否按单脉冲相位着色非常重要。误读风险是把相关性当成唯一机制判据，而不检查 \(\alpha\)、残差和时间 bin 选择。

图八：counts-space 残差图。横轴为能量道或重建能量 \(E\)，纵轴通常是 \((\mathrm{data}-\mathrm{model})/\sigma\)。若同步辐射模板在低能端连续同号偏离，说明低能斜率可能不对；若在 \(E_{\rm pk}\) 附近出现波状残差，说明谱峰宽度或曲率不匹配；若只在探测器交界能段异常，应优先检查响应矩阵和交叉定标。读图时不要只比较总 \(\chi^2\) 或 \(\ln {\cal L}\)，因为两个模型的全局统计量接近时，残差形状仍可能显示完全不同的物理失败位置。

后续阅读路径

第一条路径是从经典内激波到经验谱挑战。先读 Rees 与 Meszaros 关于非稳态壳层追赶和内部耗散的经典工作，目标是掌握 \(R_{\rm is}\)、\(\eta_{\rm is}\) 和中心引擎变时标如何进入 prompt 机制。随后回到 Band 经验谱与 BATSE/Fermi 时间分辨谱结果，重点看 \(\alpha\)、\(\beta\) 和 \(E_{\rm pk}\) 如何成为物理模型的入口。检索关键词可围绕 internal shocks、optically thin synchrotron、low-energy spectral index 和 synchrotron line of death。

第二条路径是同步辐射修正方案。读 marginally fast cooling 时，要看作者如何让 \(\nu_c\) 接近 \(\nu_m\)，从而避免宽频段的 \(\alpha=-3/2\)；读 decaying magnetic field 模型时，要看 \(B'\) 随半径或共动时间衰减后电子冷却历史如何改变；读 continuous acceleration 或 slow heating 时，要看电子分布是否真的不再是标准快冷稳态分布。每篇论文都应同时检查 \(\alpha\)、\(E_{\rm pk}\)、效率、光变和参数自然性，而不是只看低能谱指数是否被调到 \(\alpha\sim -1\)。

第三条路径是从本讲走向第 \(4/6\) 讲的竞争机制。本讲故意不展开光球、亚光球耗散和磁化喷流，但这些方向正是内激波同步辐射张力推动出来的。读光球模型时，应比较 \(R_{\rm ph}\) 与 \(R_{\rm is}\) 的角色，理解热峰如何通过角向效应、多温叠加和 Compton 化展宽；读磁化喷流与 magnetic reconnection 时，应关注能量载体从重子动能变为 Poynting flux 后，效率、偏振和多区辐射如何改变。

第四条路径是观测诊断技术。建议选择一篇 Fermi/GBM 明亮 GRB 的时间分辨谱论文，重新制作一个表格：每个时间 bin 写下 \(\alpha\)、\(E_{\rm pk}\)、能量通量、最佳模型、低能残差和误差条。然后逐行判断该谱挑战的是 \(\alpha=-3/2\) 还是 \(\alpha=-2/3\)，并说明结论是否依赖 Band、CPL 或同步辐射模板。这个练习能把 line of death 从口号转化为可重复的统计判断。

第五条路径是把 prompt 与后续能量预算连接起来，但只作为后续课程的预习。本讲只把 \(\epsilon_\gamma\sim E_\gamma/(E_\gamma+E_{\rm k,afterglow})\) 作为效率接口，不展开外激波动力学。继续阅读时，可以先记录 prompt 辐射效率与内激波 \(\eta_{\rm is}\) 的数量级张力，等到后续讲 afterglow 时再系统讨论剩余动能、外激波建模和 prompt-afterglow 能量闭合。

下一讲建议

第 \(4/6\) 讲最自然的方向是“光球辐射、亚光球耗散与谱展宽”。本讲已经说明低磁化内激波薄同步辐射在效率、快冷斜率和 \(\alpha>-2/3\) 方面存在压力；下一讲应从光球半径 \(R_{\rm ph}\) 出发，比较热辐射、多温叠加、角向效应和亚光球 Compton 化如何生成非热状 prompt 谱，并明确它们如何回应 \(\alpha\)、\(E_{\rm pk}\)、谱宽和效率问题。

第二个自然方向是“磁化喷流与 magnetic reconnection prompt emission”。本讲的耗散来自低磁化壳层碰撞，磁场只通过 \(\epsilon_B\) 作为微物理参数出现；下一讲或其后可讨论 Poynting-flux dominated jet 中磁能如何释放，磁重联如何改变发射半径、辐射效率、多区同步辐射、GeV 延迟和偏振预言。边界要清楚：这不是对本讲公式的简单改名，而是能量载体和耗散机制的改变。

第三个方向应留给第 \(5/6\) 或第 \(6/6\)：prompt 与 afterglow 的能量预算、早期外激波和多信使约束。本讲只把 \(\epsilon_\gamma\sim E_\gamma/(E_\gamma+E_{\rm k,afterglow})\) 作为效率讨论接口，不推导 afterglow 动力学。后续课程再把 \(E_{\rm iso}\)、剩余动能、外部介质、喷流开角和早期余辉观测连接起来，检验 prompt 机制是否与全局能量闭合一致。
